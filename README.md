# Rahul - Personal Developer Portfolio

Modern, responsive personal developer portfolio built with semantic HTML5, modern CSS3, and vanilla JavaScript.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FRahultn56%2FPortfolio-)

---

## 🌟 Highlights & Features
- **Modern Clean UI**: Beautiful typography, responsive flex/grid layout, and custom gradient accents.
- **Dark / Light Mode**: Seamless theme switcher with persistent `localStorage` state.
- **Dynamic Typing Effect**: Animated role switcher for Full Stack Web Developer & IT Student.
- **Skills Matrix**: High-resolution vector icons for HTML, CSS, JavaScript, Java, C, Node.js, Express, and MongoDB.
- **Featured Live Projects**: Direct links to working repositories and live deployments.
- **Interactive Contact Form**: Client-side validation with instant visual confirmation.
- **Mobile Responsive**: Custom hamburger menu and touch-friendly navigation.
- **100% Vercel Ready**: Preconfigured with `vercel.json` for zero-config global deployment.
